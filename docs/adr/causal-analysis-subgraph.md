# ADR：因果分析子图——相关非因果的三层兜底，合成数据才下强度结论

日期：2026-10-29
状态：已接受

## 背景

第 8 周做 insight 子图，验收是「构造咖啡→入睡延迟合成数据（≥120 天、标 synthetic），输出可解释
线索（相关、非因果），附 N 和 p 值，措辞过滤器阻断因果词」。核心风险：相关不等于因果，且自录
数据样本小、带选择偏差，容易误下结论。

## 决策

1. 子图 query → analyze → explain 单次执行，接入入口层 `dispatch`，无需 checkpointer；
2. 相关性计算用 scipy（Pearson/Spearman），按 |r| 最大选最佳滞后，纯函数、确定性；
3. LLM 只翻译统计结果、不做统计判断，且只在合成数据上启用；失败/空/超限回退确定性模板；
4. 措辞过滤器确定性替换 导致/因为/引起/确诊/诊断，输出前兜底；
5. 自录真实数据不调 LLM，只给趋势描述、不做显著性断言；
6. 演示指标对（caffeine_mg / sleep_onset_latency_min）以常量写死，指标字典表推迟到第 9 周。

## 备选方案

- 做因果推断（格兰杰等）：被否，超范围且易被误解为因果结论。
- 真实数据也走 LLM 翻译：被否，有泄漏「显著/强相关」措辞的风险，确定性模板更安全。
- 时间对齐用 pandas：被否，冻结契约只锁 scipy，纯 Python 日期交集对齐依赖更少。
- 本周就建指标字典表：被否，固定一对演示暂无必要，留第 9 周随参考范围表一起建。

## 后果

- 「相关非因果」由 过滤器 + 分级措辞 + 模板 三层保证，不依赖 LLM 自觉。
- 本周只支持固定一对指标；扩展需先引入指标字典（第 9 周）。
- `final_insight` 暴露结构化字段（n / r / p / lag / grade / synthetic），便于评估与前端展示。
