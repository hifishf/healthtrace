# ADR：追问选择用鉴别价值权重排序，候选集收敛用高置信档指标

日期：2026-10-21
状态：已接受

## 背景

第 3 周 `select_followup_questions` 用 `prevalence desc` 选下一个追问，并暴露候选集。
到第 4 周要「候选集逐轮缩小可量化」，但候选集是并集，基数不随追问减少；真正收敛的
是「命中已采集症状越多」的那批疾病。

## 决策

1. 追问选择改为 `discrimination_weight desc`（id 升序兜底），优先问鉴别价值最高的症状。
2. 「缩小」量化指标用 `top_tier_size`：命中数并列最高的候选个数，单调不增、永不塌空。
3. 指标暴露到 `/triage` 响应与前端开发者面板，但**不进病人聊天**（指标是开发者/评估信号）。

## 备选方案

- 继续按 prevalence 排序：被否，问大众症状区分度低。
- 用候选总数衡量缩小：被否，并集总数不收缩，无法证明收敛。
- 严格交集：被否（见 ADR candidate-set-union-ranking），空交集会误判无候选。
- 统计信息增益：更好但需条件概率/熵，超出 MVP，列为后续项。

## 后果

- 追问更快收窄（首轮 8 候选 → 问一句特异性症状可缩到 1）。
- 「缩小」有了可复现、可测试的数字（黄金链 8→4→1），可写进简历。
- 当前 discrimination_weight 是逆文档频率近似（人工标注 1-5 的占位），后续可人工校准。
