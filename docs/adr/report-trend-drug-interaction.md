# ADR：报告趋势与用药冲突——确定性规则判结论，LLM 只做转写不判断

日期：2026-11-02
状态：已接受

## 背景

第 9 周做报告解读 + 用药冲突，验收是「导入三年 LDL 序列输出持续上升趋势、新增药物触发
交互冲突告警、非法 CSV 被校验拦截」。核心风险：体检趋势与用药交互都涉及健康安全边界，
若让 LLM 直接判断，可能把「波动」说成「恶化」、把「中等」说成「严重」，且结果不可复现、
不可审计。

## 决策

1. 纵向趋势用纯函数 `analyze_metric_trend`：相邻变化量全正=持续上升、全负=持续下降、
   全持平=基本平稳、其余=波动，附变化量/变化率 + 参考范围判定，全程确定性；
2. 药物交互用确定性规则引擎 `check_drug_interactions`：去重 → 两两查 `drug_interactions`
   表 → 按 禁忌>严重>中等>轻微 排序 → 打 high_risk（禁忌/严重），全程确定性；
3. LLM 只预留「把命中结果转写成建议话术」的角色，本周不启用；
4. 数据导入 `import_metric_rows`：纯格式校验 + 单位与参考范围比对，坏行进 rejected、
   不阻断其余合法行，合法行按 `(user_id, metric_code, recorded_date)` 覆盖入库；
5. 指标码→中文名用模块常量映射（未建指标字典表），延续第 8 周的常量方案。

## 备选方案

- 让 LLM 直接判趋势/冲突：被否，安全边界不可依赖概率系统（与红旗检查同一思路）。
- 本周建指标字典表：被否，冻结契约只锁参考范围/交互两张表，常量映射够用，YAGNI。
- CSV 解析用 pandas：被否，简单行数据用标准库 `csv` 足够，不加重依赖。

## 后果

- 三条验收全部确定性、可复现、可审计，测试可直接断言（断言 #10 / #9 / 非法 CSV 拦截）。
- LLM 不参与判断，成本为零，无越界措辞风险。
- 趋势规则只覆盖单调/波动/平稳，不覆盖「先升后降」等复杂形态（当前验收不需要）。
- 指标中文名仍是常量，指标变多时再引入字典表。
